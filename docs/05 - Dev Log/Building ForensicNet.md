# 📝 Dev Log: Building ForensicNet (Custom Multi-Stream Architecture)

> [!INFO] Session Context
> * **Objective:** Design and implement a custom neural network architecture targeting microscopic pixel residual noise and frequency domain artifacts to complement EfficientNet-B0's semantic features.
> * **Related Notes:** [[ForensicNet]], [[Model Overview]], [[Model Version History]]

---

## 🛠️ What Was Done

1. **Architecture Research & Design:**
   - Designed a tri-stream neural network architecture (`ForensicNet`) in `backend/ml/custom_model.py`.
   - **Stream A (Noise Residuals):** Implemented `BayarConv2d` layer enforcing zero-sum 5x5 filter kernels ($\sum w = 0$, center weight = -1) to suppress scene semantics and extract prediction errors.
   - **Stream B (Frequency Spectrum):** Built `compute_fft_spectrum()` computing 2D Discrete Fast Fourier Transform log-magnitude spectrums ($S = \log(1 + |\mathcal{F}(x)|)$) with `fftshift` DC centering and min-max normalization.
   - **Stream C (Spatial RGB):** Constructed standard 5-layer CNN processing raw RGB pixel input.
   - **Fusion Head:** Concatenated stream outputs (256 + 128 + 256 = 640 dimensions) into a dense classification head (`Linear(640, 256)` -> `ReLU` -> `Dropout(0.5)` -> `Linear(256, 2)`).

2. **Training Pipeline Implementation (`backend/ml/train_custom.py`):**
   - Built custom training script with gentle forensic data augmentations (`Resize(240)` -> `RandomCrop(224)` -> `RandomRotation(5)`).
   - Integrated hardware optimizations: `persistent_workers=True`, `prefetch_factor=4`, pin memory, TF32 execution, and background GPU utilization monitoring (`GPUUtilMonitor`).

---

## 💡 Decisions Made

- **Decision 1:** Use `BayarConv2d` over standard unconstrained 3x3 convolutions to explicitly force residual noise extraction rather than semantic feature learning.
- **Decision 2:** Implement 2D FFT magnitude spectrum analysis to detect periodic grid artifacts generated by GAN transposed convolutions or diffusion interpolation filters.
- **Decision 3:** Train from scratch rather than fine-tuning a pre-trained backbone to ensure all weights adapt specifically to forensic signatures.

---

## ⚠️ Issues Encountered

- **Issue:** Initial parameter weight constraining in `BayarConv2d` was written using in-place operations (`self.conv.weight.data[:, :, 2, 2] = -1.0`), which caused autograd tracking conflicts during initial testing.
- **Resolution:** Replaced in-place mutations with non-in-place tensor masking logic inside `constrain_weights()`.
