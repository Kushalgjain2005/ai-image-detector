## 📐 Overview

The `Detector` page (`frontend/src/pages/Detector.tsx`) serves as the primary operational workspace for the web application. It integrates the upload dropzone (`Scanner`), model switching toggle (`ModelSelector`), confidence readout (`Results`), and terminal log simulation.
